# LLM Chat Exporter — Release Log

## v0.7.39 — 2026-10-01

Claude
• Fixed images appearing twice in exports.
• Your uploaded images are now exported in original quality (ZIP), named by their real format.
• Artifacts made with Claude's new artifact pages are exported in their latest version, with a link to the online page.
• Files Claude created and then edited are exported in their final version; files Claude sends you are always included.
• Research reports and web-search answers keep their sources: numbered references plus a Sources list.
• Thinking summaries are included with "Include reasoning".
• Drawings and diagrams Claude renders in the chat are saved as SVG/HTML files.
• Dictated messages are marked with 🎙️, support notices are kept, and images that fail to download are clearly marked.
• Claude Docs documents are linked from the export (their content isn't exported yet).

ChatGPT
• Charts drawn by Python code are now exported as images.

Gemini
• Export file names no longer end with "- Google Gemini".

## v0.7.30 — 2026-05-12

Options page now lets you set per-LLM defaults
Added 'Inline images' toggle in the popup - turn it off to skip image downloads and get a fast, text-only export
ChatGPT voice-mode messages now export with the transcribed text
Added support for message dates
Fixed Claude artifacts, text blocks and multi-choice questions in exports. Also fixed some other reasoning items

## v0.7.15 — 2026-05-10

• Added support for gemini.google.com — text, images, file uploads, thinking, and AI-generated images (Nano Banana / Imagen).
• ChatGPT: cleaner exports of chats that use file search or image generation — no more leaked tool boilerplate or missing pictures.
• ChatGPT: fixed an issue where attached files would fail to download with a 403 error.

## v0.6.3 — 2026-05-06

• Claude.ai and ChatGPT.com support.
• Two export formats:
  – Markdown — single .md file with images embedded as base64.
  – ZIP — folder layout with assets / files / artifacts and the .md referencing them.
• Toggles: include reasoning, inline pasted text files, render Markdown attachments inline.
• Options page for setting defaults.
• No accounts, no telemetry — extraction runs locally in the browser.
