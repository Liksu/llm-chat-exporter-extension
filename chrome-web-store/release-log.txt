# LLM Chat Exporter — Release Log

## v0.7.38 — 2026-10-01

Fixed duplicated images in Claude exports
Image files in ZIP exports are now named after their actual format (Claude serves uploaded photos as WebP)
Claude images that fail to download are now marked as such instead of looking like a skipped image
Claude: ZIP exports now contain your uploaded images in original quality, not the downscaled preview
Claude: published artifacts (the new claude.ai/artifact pages) are exported, in their latest version, with a link to the page
Claude: files Claude created and then edited are exported in their final version
Claude: files Claude sends you are exported even when they don't appear in the chat's file list
Claude: Research reports and web search answers keep their sources (numbered references plus a Sources list)
Claude: thinking summaries are exported (claude.ai no longer keeps the full reasoning text)
Claude: drawings and diagrams Claude renders in the chat are saved as SVG/HTML files
Claude: dictated messages are marked with 🎙️; support notices are kept; internal blocks no longer show up as unknown
Gemini: file names no longer end with "- Google Gemini"
ChatGPT: charts drawn by Python code are exported as images
Images Claude sends you now display inline in Markdown exports
Claude Docs documents are linked from the export (their content isn't included yet)

## v0.7.37 — 2026-08-03

Add support for the Claude Cowork

## v0.7.36 — 2026-06-15

ChatGPT Deep Research and other Apps SDK reports are now included in exports

## v0.7.34 — 2026-06-12

ChatGPT canvas and sandbox-generated files are now included in exports

## v0.7.30 — 2026-05-12

Options page now lets you set per-LLM defaults
Added 'Inline images' toggle in the popup - turn it off to skip image downloads and get a fast, text-only export
ChatGPT voice-mode messages now export with the transcribed text
Added support for message dates
Fixed Claude artifacts, text blocks and multi-choice questions in exports. Also fixed some other reasoning items

## v0.7.15 — 2026-05-10

• Added support for gemini.google.com — text, images, file uploads, thinking, and AI-generated images (Nano Banana / Imagen).
• ChatGPT: cleaner exports of chats that use file search or image generation — no more leaked tool boilerplate or missing pictures.
• ChatGPT: fixed an issue where attached files would fail to download with a 403 error.

## v0.6.3 — 2026-05-06

• Claude.ai and ChatGPT.com support.
• Two export formats:
  – Markdown — single .md file with images embedded as base64.
  – ZIP — folder layout with assets / files / artifacts and the .md referencing them.
• Toggles: include reasoning, inline pasted text files, render Markdown attachments inline.
• Options page for setting defaults.
• No accounts, no telemetry — extraction runs locally in the browser.
