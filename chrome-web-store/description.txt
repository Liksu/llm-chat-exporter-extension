Your AI conversations, saved as files you actually own.

You wrap up a useful conversation with Claude, ChatGPT, or Gemini — full of decisions, code, half-finished docs, that one diagram you'll want to look at again next week. Then the tab closes, the chat scrolls off, and you're hunting for a screenshot of something the model said three days ago.

LLM Chat Exporter turns whatever chat you're on into a clean Markdown file (or a ZIP) — in one click, locally, without uploading anything anywhere.

━━━ WHAT YOU GET ━━━

• Everything in the chat, not just the text. Inline images, file uploads, pasted snippets, Claude artifacts, ChatGPT canvas docs, Gemini-generated pictures (Nano Banana / Imagen) — all captured. The model's thinking and tool calls too, if you want them.

• Two output formats, both ready to use:
  – Markdown — a single .md file with images embedded as base64. Drop it straight into Obsidian, Notion, your repo, or any Markdown editor. Looks right immediately.
  – ZIP — a tidy folder with images in /assets, uploads in /files, artifacts in /artifacts, and the .md linking to them. Better for big chats with lots of attachments.

• Ready to feed back into another LLM. The .md is plain, well-structured text — paste it into a new Claude / ChatGPT / Gemini conversation as context, or hand it to a local model. Nothing proprietary, nothing locked.

━━━ WORKS WITH ━━━

• Claude.ai — text, images, file uploads, artifacts (including files written by the create_file tool), thinking blocks, tool calls.
• ChatGPT.com — text, images, file uploads, reasoning. Handles file-search and image-generation messages cleanly, with no leaked tool boilerplate.
• Gemini.google.com — text, images, file uploads, thinking, and AI-generated images.

━━━ OPTIONS ━━━

A few toggles in the popup (and an Options page for defaults):
• Include reasoning — thinking blocks + tool calls, off by default.
• Inline text uploads — paste .md / .txt / .json files directly into the body instead of keeping them as separate attachments.
• Markdown attachments — render .md uploads and artifacts as actual markdown, not wrapped in a code block.

━━━ PRIVACY ━━━

Reads the active tab, only when you click Export. No accounts, no analytics, no telemetry, no remote server. The only thing stored is your default-format preferences (in chrome.storage.sync).

For Gemini, the extension fetches attached and inline images from Google's asset CDNs (the same ones the page already loads them from) so they can be embedded into the export. Those bytes never leave your browser.

━━━ PERMISSIONS ━━━

• activeTab — read the chat tab when you trigger an export.
• storage — remember your option toggles.
• declarativeNetRequestWithHostAccess — rewrite CORS response headers from Google's image CDNs so Gemini images can be embedded. Scoped to those CDN hosts only.
• Host access to claude.ai, chatgpt.com, gemini.google.com — run the extraction scripts.
• Host access to *.googleusercontent.com, *.usercontent.google.com, and lh1.google.com–lh7.google.com — fetch Gemini-uploaded files and inline / generated images.

━━━ HOW TO USE ━━━

1. Open a conversation on claude.ai, chatgpt.com, or gemini.google.com.
2. Click the LLM Chat Exporter icon.
3. Pick Markdown or ZIP, set your toggles, hit Export.
4. The file lands in your normal downloads folder.

Defaults configurable on the Options page (gear icon in the popup).
